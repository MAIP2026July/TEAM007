# Offline Browser Prototype

Open `index.html` in any modern browser. Nothing needs to be installed, and no server, model, credentials or external data source is used. The four sample cases are synthetic.

This demonstrator implements the *interaction*, not the proposed AI model. It runs deterministic field and demo-reference checks only. A sample reference such as `TEST-001` is considered **supplied**, not verified. A human reviewer retains all real approval authority.

For a short demo: choose **Fields supplied**, run the assessment; choose **Verification evidence missing**, run again; choose **Evidence is ambiguous** and inspect the required review path; choose **Unsupported evidence claim** and show why an unsupported assertion is not accepted. Finally enter a disposition and click **Export advisory summary (JSON)**.

The prototype does not retrieve an approved Automotive SPICE criteria library or connect to an enterprise change-request repository. Do not input proprietary records.
