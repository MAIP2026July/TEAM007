# Prototype README / Link

- **Project:** AI-Enhanced ASPICE Compliance Checker - TEAM007
- **Mode:** Offline browser demonstration (single HTML file, no installation or external services)
- **Open:** [`../prototype/index.html`](../prototype/index.html)
- **What it demonstrates:** structured record fields, deterministic findings, source/reference visibility, clear review routing, human disposition and a local JSON summary export.
- **What it does not demonstrate:** a running generative AI model, retrieval of approved engineering guidance, live RV&S integration, or completed ASPICE compliance evaluation.

Open the HTML file in a modern browser and select the supplied synthetic scenarios. No enterprise records are required or transmitted. Screenshots and the proposed AI workflow are available under `../Appendix/`.

If you publish through GitHub Pages, this can be served as a static file. A live hosted URL should only be added when it actually exists.
